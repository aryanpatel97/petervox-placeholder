Installation

To customize the template styles using SCSS, install Node.js and Sass on your system.

1. Install Sass 
npm install -g sass

2. Compile SCSS 
sass --watch assets/scss/style.scss assets/css/style.css

Make sure Node.js is installed before running SCSS commands.

Customization

Follow these simple steps to customize your legal website branding, logos, and footer copyright text.

How to Change Logo

To update the brand logo, locate the <header> and <footer> sections in your HTML files and update the image source path. 

<!-- Locate the logo class and update the src -->

<div class="white-logo">
    <img class="w-100 py-2" src="assets/image/white-brand-logo.svg" alt="">
</div>

<div class="dark-logo mx-auto">
    <img class="w-100 py-2" src="assets/image/final.svg" alt="">
</div>

How to Change Copyright Text

The copyright information is located at the bottom of the <footer>. Simply search for the "copyrights-text" class and edit the text. 

<!-- Update the text within the copyright paragraph -->

<div class="copyrights-text">
    <p>Copyright 2026 <a href="#">Premier & Team</a>.
    All rights reserved.</p>
</div>

Theme Colors

Edit theme colors globally from the SCSS variable.scss file. 

$theme-primary   : #34373e;
$theme-secondary : #b08d59;
$theme-light     : #ededed;
$black: #000000;
$white: #ffffff;
$text-primary: #25345e;
