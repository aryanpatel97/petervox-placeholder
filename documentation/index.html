Introduction

Thank you for purchasing Petervox & Team. We appreciate your trust in our professional legal website template designed specifically for law firms, attorneys, legal advisors, and consulting agencies.

Petervox & Team is a premium HTML template built with modern UI design and responsive layouts. It includes legal service pages, attorney showcases, testimonials, consultation forms, and business-focused sections tailored for legal professionals.

This documentation will help you understand installation, customization, theme structure, SCSS workflow, and all essential files needed to build your legal website quickly and efficiently.

Installation

To customize the template styles using SCSS, install Node.js and Sass on your system.

1. Install Sass 
npm install -g sass

2. Compile SCSS 
sass --watch assets/scss/style.scss assets/css/style.css

Make sure Node.js is installed before running SCSS commands.

Customization

Follow these simple steps to customize your legal website branding, logos, hero video, and footer copyright text.

How to Change Logo

To update the brand logo, locate the <header> and <footer> sections in your HTML files and update the image source path. 

<!-- Locate the logo class and update the src -->

<div class="white-logo">
    <img class="w-100 py-2" 
    src="assets/img/white-brand-logo.svg" alt="">
</div>

<div class="dark-logo mx-auto">
    <img class="w-100 py-2" 
    src="assets/img/final.svg" alt="">
</div>

How to Change Copyright Text

The copyright information is located at the bottom of the <footer>. Simply search for the "copyrights-text" class and edit the text. 

<!-- Update the text within the copyright paragraph -->

<div class="copyrights-text col-md-6 col-12 
text-uppercase order-2 order-lg-1 
text-lg-start text-end">

    DESIGN BY THE PROTHEMEBZAR

</div>

How to Change Hero Video

By default, the hero section displays a static image. To use a video background, comment out the <img> tag and uncomment the <video> tag in the Hero Section and add your video link. 

<!-- 1. Comment the image tag -->

<!-- 
<img src="assets/img/v1.png" 
class="hero-video h-100 w-100 object-fit-cover" alt=""> 
-->


<!-- 2. Uncomment the video tag and update the source path -->

<video autoplay muted loop playsinline class="hero-video">
    <source src="assets/video/your-video.mp4" type="video/mp4">
    Your browser does not support the video tag.
</video>

Theme Colors

Edit theme colors globally from the SCSS variable.scss file. 

$theme-primary   : #34373e;
$theme-secondary : #b08d59;
$theme-light     : #ededed;
$black: #000000;
$white: #ffffff;
$text-primary: #25345e;

Customize Website Colors

You can easily update your website branding colors from the SCSS variable file. Modify the primary, secondary, background, and button colors globally.

assets/scss/_variable.scss
$theme-primary

Dark background color

$theme-secondary

Main gold branding color

$theme-soft

Light background sections

Once you save the changes, all buttons, headings, cards, overlays, and website elements will automatically update.
